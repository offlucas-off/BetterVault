Como Usar a Biblioteca em 3 Passos

  1. 1. Escolha uma Estante (ou pesquise no topo): Na Coluna 1 você filtra por assunto ou clica num formato (Livros, Vídeos, Fotos ou Projetos).
  2. 2. Leia a Capa em 1 Minuto: Cada cartão na Coluna 2 funciona como a capa de um livro real: explica para que serve sem obrigar você a abrir arquivos gigantes.
  3. 3. Vá Direto ao Ponto: Na Coluna 3, clique em qualquer item de Ir Direto ao Ponto para abrir a página exata do PDF, o minuto do vídeo ou o trecho do código!
  4. + Guardar Novos Materiais: Use o botão + Guardar na Biblioteca no topo para cadastrar novos itens em 3 passos, sem usar terminal.

Servidor Local & CLI (bibliotecario.py)

Para gravar arquivos diretamente no disco ou usar via agentes de IA no terminal:

Iniciar servidor local (porta 4325)
python bibliotecario.py servir --porta 4325
Busca instantânea (< 5 ms)
python bibliotecario.py buscar "video"
Sincronizar Capas → Índices + JSON
python bibliotecario.py sincronizar
Rodar autoteste de integridade
python bibliotecario.py testar
